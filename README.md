# 东南大学网安法学学习记录
## 总揽
在东南大学网络空间安全学院和法学院学习期间的一些资料，可能有助于学习，能通过其他公开渠道获取的就不放在这里了。目前已经更新的有：
- 刑法学：总论 (24fall)，分论 (25spring), 刑事诉讼法学 (25spring)，犯罪学 (25fall)
- 民商法：总论 (24fall)，商法学 (25spring)
- 行政与宪法类：行政诉讼法学 (25spring)，国际公法 (25spring)，法理学 (23fall)，宪法学 (24spring，24fall，25fall)
- 网安相关课程：网络空间安全法律基础 (25spring)，网络空间安全数学基础 (24fall)，离散数学(2020AB, 2021AB,2022AB,2023AB)
- 通用资料：网安学院培养方案，SRTP参与指南

宪法学23fall、行政法学、民诉、民分为网安+法学单考，试题价值不大，仅涉及纯粹知识点的考察，不做整理 (也记不住了)

24fall宪法学考试卷为23级法学班试卷，由LQaa同学回忆提供

25fall宪法学考试卷为24级法学班试卷，由24级C6H12O6同学回忆
